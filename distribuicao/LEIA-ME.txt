UPBOX — MYSQL

Extraia TODO o ZIP. Instale Java 17 e MySQL.
Crie o banco upbox no MySQL somente se ainda não existir:
CREATE DATABASE IF NOT EXISTS upbox CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

Edite application.properties ao lado de upbox.jar: localhost:3306/upbox,
usuário root e sua senha do MySQL. Não envie configuração preenchida ao GitHub.
Execute iniciar-upbox.bat. Mantenha a janela aberta e acesse localhost:8080.

A conta é criada automaticamente em banco novo:
LOGIN: administrador
SENHA INICIAL: admin

No primeiro login, troque a senha em Configurações para liberar o sistema.
Informe admin em Senha atual e uma nova senha com pelo menos 8 caracteres.
Reiniciar não redefine senhas nem duplica conta. Em banco existente, a senha
anterior é preservada. A senha admin é inicial, exclusiva da demonstração local.
Use Ctrl+C para parar.

Não precisa de Maven, .env ou arquivo local adicional. O script não apaga bancos.
Confira Java 17, serviço MySQL, usuário/senha, banco upbox e porta 8080 se falhar.
Detalhes técnicos em logs/upbox.log. Mude o endereço no navegador se alterar a porta.
Faça backup antes de atualizar uma instalação já utilizada.

Não existe conversão automática de PostgreSQL. MySQL 5.7.44/8.0.44 são as versões
de referência da homologação; outras versões e MariaDB exigem validação própria.
